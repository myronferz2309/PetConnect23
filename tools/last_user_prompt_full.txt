------------------------------------------------------------

• Available pet listings
• AI recommendation candidates

status === "available"

------------------------------------------------------------

recommendation system.

If a recommended pet is adopted:

1. Firestore status changes to adopted.
2. It must no longer be eligible for AI recommendations.
3. It must not appear in future Match results.
4. It must not appear in the KNN/RF/LR production candidate list.

The 49-pet AIML training/reference dataset must NOT be modified when
a real pet is adopted.

Only the Firestore production record changes.

adopted again.

Verify current Firestore status.

If status !== "available":

Do not complete the adoption.

Show an appropriate message such as:

"This pet is no longer available."

Use the existing UI style.
